# Nine Lives 3D (web)

Play: https://peter23023.github.io/ninelives3d/

A 3D skate runner starring the Nine Lives cat. Works in phone and computer browsers
(swipe on a phone; arrow keys / WASD + Space on a computer). No login, no ads, no tracking.
Progress is saved in your browser.

This folder is the finished web build of the Nine Lives 3D project (TeaVM output of the `web` module).
